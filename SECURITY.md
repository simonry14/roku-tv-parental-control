# Security

Roku TV Parental Control runs on your home network and controls a TV, so a way around it matters even when it isn't dangerous in the usual sense.

**Please report privately** anything that lets someone:

- open the dashboard or change the rules without the PIN,
- reach the dashboard from outside the home network,
- read another household's data (for example through notifications), or
- quietly stop the rules from being applied without the parent being told.

Use **Security → Report a vulnerability** on this repository's page. Please don't open a public issue for these.

Known and documented limits (the PC can be unplugged, the TV's _Control by mobile apps_ setting can be changed, the dashboard uses plain HTTP on the home network) are described in the README and in [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md). Ideas to make them harder to get around are welcome as ordinary issues.
